# Source map

Where the Lua system lives in the runtime. All paths are under `Fable2Native/`.

## Runtime

| File | Responsibility |
|---|---|
| `include/f2/native_script.h` · `src/native_script.cpp` | `NativeScriptVM` — the embedded Lua 5.1 VM, native binding, object handles, callback refs, coroutine-safe args, the auto-stub |
| `include/f2/native_bindings.h` · `src/native_bindings.cpp` | the native API: managers, hero/entities, message events, gameflow/timing/search, `RunScript`, `print` capture |
| `include/f2/native_bnk.h` · `src/native_bnk.cpp` | `BnkReader` — v3 BNK parse + zlib inflate |
| `include/f2/native_message.h` | `MessageBus` — the message-event queue |
| `include/f2/native_game.h` · `src/native_game.cpp` | `NativeGame` — `enable_scripting`, `boot_game_scripts`, `load_quest_scripts`, the manager tick |
| `include/f2/native_lua_catalog.inc` | generated native-name set (from the decomp catalog) used by the auto-stub |

## Vendored Lua (patched)

| File | Patch |
|---|---|
| `third_party/lua-5.1.5/luaconf.h` | `LUA_NUMBER = float` (32-bit numbers) |
| `third_party/lua-5.1.5/lundump.c` | `LoadSize` reads a 4-byte `size_t`; header advertises `sizeof(size_t)=4` |
| `third_party/miniz/` | zlib inflate for the BNK |

## Tests

| File | Covers |
|---|---|
| `tests/native_core_tests.cpp` → `test_boot_game_scripts` | boot loads the bank; ranked stub-miss list |
| `tests/native_core_tests.cpp` → `test_run_real_quest` | `MyFirstQuest` runs to its completion print |

!!! note "`F2_CHECK`, not `assert`"
    The suite builds under `RelWithDebInfo` (defines `NDEBUG`, strips `assert`). The
    scripting tests use `F2_CHECK`, which fires in every configuration — so a green
    run means the assertions actually ran.

## Tooling (Python + tools)

| Path | Purpose |
|---|---|
| `tools/lua_mod/script_index.py` | list / search / extract BNK entries; `entry_bytes` (canonical inflate) |
| `tools/lua_mod/bnk_repack.py` | read / repack a BNK |
| `tools/lua_mod/luadis51.py` | Lua 5.1 disassembler (little-endian, float numbers) |
| `tools/lua_mod/decompile_all.py` | decompile the whole bank to a readable source tree |
| `Fable2AssetBrowser/source/build_lua_cli/f2lua_decompile.exe` | LuaQ → readable Lua source |

## The decompiled reference tree

`lua-decompiled/` holds a full readable decompilation of both banks — generated by
`decompile_all.py`, not shipped game code. See its `README.md`.
