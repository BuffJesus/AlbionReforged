# Contributing

The active direction is the hybrid port described in the [README](README.md).
New independent services belong in `native/`, with host-owned interfaces and
explicit bounds, errors and lifetime. The old `Fable2Native` source is retained
for reuse, not as the current product or default test target.

Run the native-service configure/build/CTest commands in the README. Keep game
integration evidence distinct from synthetic, corpus and original-instruction
checks. Preserve original execution until the replacement's source identity,
bytes, statuses, ownership and live scope are verified.

Do not commit game dumps, extracted/cooked assets, generated PPC output, SDKs,
captures, build artifacts or credentials. Preserve unmerged source work and
existing worktrees. Update current status in place rather than appending competing
checkpoint narratives to every document.
